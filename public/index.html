🎬 VidFun Embed API

Not a streaming site. One embed endpoint + one JSON API. Give it a TMDB or IMDb id — it scrapes direct streams where possible and falls back to provider iframes.

JSON API

EndpointReturns
GET /api/sources/movie/:idScraped direct streams (verified), subtitles, per-provider iframe URLs + availability, scrape trace. Add ?scrape=0 to skip scraping.
GET /api/sources/tv/:id/:s/:e
GET /api/scrape?url=…Scrape any VidSrc-style embed URL → .m3u8/.mp4 + subtitles (follows the data-hash → rcp → prorcp chain, unpacks packed JS).
GET /api/proxy/stream?url=…&referer=…CORS/Referer proxy that rewrites HLS playlists (segments + URI="…" keys).
GET /api/providers · /api/healthProvider registry / status.

Providers: VidLink · Videasy · VidFast · VidSrc.cc · VidSrc (.xyz, scraped) · VidSrcMe (scraped) · VidCore · AutoEmbed · SuperEmbed · 2Embed · Embed.su — edit one file (src/providers.js) when a domain rotates. Set TMDB_API_KEY to convert IMDb↔TMDB ids and get titles/episode counts.
